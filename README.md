# ch-github

这是我的第一个 GitHub 仓库，由 AI 助手协助创建并维护。

## 这个仓库是干什么的

用来练手和验证 GitHub 的完整流程：建仓库 → 写文件 → 提交 → 开 PR → 合并。

## 目录约定

| 目录 | 用途 |
| --- | --- |
| `notes/` | 随手记的想法、学习笔记 |
| `scripts/` | 小工具、一次性脚本 |
